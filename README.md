# bookstore-specs

The specs repository for [ihudak/bookstore](https://github.com/ihudak/bookstore): ideas, PRDs, ARDs, Epics, specifications and designs, written by the shipwright plugin family's commands under `specifications/<KIND>-<KEY>-<slug>/`, with their session bookkeeping (cost, feedback, follow-ups). Point `SPECS_PATH` at a clone of this repository.
